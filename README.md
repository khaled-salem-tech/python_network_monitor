# Python Network & System Monitor

A command-line network tool written in Python using only the standard library.

## Features
- Check internet connectivity (TCP connection test)
- Show hostname and local IP address
- Check open ports on your own device
- Check ports on another device (asks for confirmation if the target is outside your local network)
- Log every action with a timestamp to `monitor.log`

## Usage
```
python monitor.py
```

## Notes
Only scan devices and networks you own or have permission to test.
